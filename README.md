# Калькулятор накладного ВСП

[![Pages](https://github.com/lev-oxr/eddy-current-probe-calc/actions/workflows/pages.yml/badge.svg)](https://github.com/lev-oxr/eddy-current-probe-calc/actions/workflows/pages.yml)
**[Відкрити калькулятор](https://lev-oxr.github.io/eddy-current-probe-calc/)** · [English](README.en.md)

Онлайн-калькулятор для електричного розрахунку накладного трансформаторного вихрострумового перетворювача (ВСП).
Він рахує робочу частоту, глибину проникнення, струм збудження, напругу холостого ходу, внесену й вихідну напругу,
а також вимоги до вимірювального каналу. Результати оновлюються одразу після зміни будь-якого параметра.

Методика — розділ 2.2 магістерської дисертації О. Е. Левченка «Автоматизація вихрострумової дефектоскопії об'єктів
зі складною геометрією поверхні» (КПІ ім. Ігоря Сікорського, кафедра приладів і систем неруйнівного контролю, 2018).

![Форма параметрів, ключові результати, переріз ВСП у масштабі й графіки f(β) і δ(β)](screenshot.png)

## Можливості

- розрахунок за формулами (2.3)–(2.20) з покроковою таблицею й тими самими номерами формул;
- аналітичний розрахунок відносної внесеної напруги U\*вн замість зчитування з годографа;
- живий годограф рис. 2.6: робоча точка, годографи зазору й електропровідності та кут між ними;
- переріз ВСП над об'єктом контролю в масштабі з глибиною проникнення вихрових струмів;
- графіки f(β) і δ(β) з рекомендованою зоною 3,5–10;
- векторна діаграма вихідної напруги;
- вимірювальний канал: підсилення, квантування, дискретизація, максимальна швидкість сканування;
- підсвічування параметрів, що виходять за рекомендовані діапазони.

## Модель і перевірка

Відносна внесена напруга двох тонких співвісних витків радіуса R над немагнітним провідним півпростором
(модель Додда — Діда), нормована так само, як годограф рис. 2.6:

```
U*вн = jπ ∫₀^∞ J₁²(x) · e^(−x·h*) · (x − q)/(x + q) dx,   q = √(x² + jβ²),   h* = (h₁ + h₂)/R
```

`npm test` перевіряє:

- формули (2.3)–(2.20) на вихідних даних розділу 2.2;
- U\*вн при β → ∞ за замкненою формулою −Q₁/₂(1 + h\*²/2) (точність 0,2 %) і за точками рис. 2.6;
- блок вимірювального каналу за ручним розрахунком.

Межі моделі (немагнітний однорідний ОК, тонкі витки, емпіричні множники методики, інженерні правила для каналу)
описано на сторінці в розділі «Про модель і обмеження». Розрахунок орієнтовний і не замінює атестовану методику контролю.

## Запуск

Збірка й залежності не потрібні. Досить відкрити `index.html` у браузері або запустити локальний сервер:

```bash
python -m http.server 8000
```

Перевірка розрахунку (потрібен Node.js):

```bash
npm test
```
